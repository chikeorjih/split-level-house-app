# From a reference image to numbers (do this once)

Look at the image **once**, in Pass 0, and write down everything below. After that, work from these notes, not the picture.

## 1. Pick a scale reference visible in the image

Use the most reliable one available:

| Reference | Size |
|---|---|
| Interior door | 80" tall, 30–36" wide |
| Kitchen counter top | 36" from the floor; base cabinet depth 24"; uppers start about 18" above the counter |
| Dining table top | 29–30" |
| Sofa seat | about 17–19"; overall depth about 34–40" |
| Standard brick course | 2⅔" |
| Floor plank | about 5–7" wide |
| Outlet or switch plate | about 4.5" tall |
| A product's own listed size | always wins: look it up when the item is named |

## 2. Measure in the image's own units

- Take the reference's length in pixels along a line roughly parallel to the object's edges. Divide the object's pixel lengths by it.
- **Perspective:** measure lengths that are about the same depth as the reference. For oblique photos, use verticals near the object (they foreshorten least) and correct widths by eye with the rule that receding edges shrink toward the vanishing point.
- **No reference visible:** use typical sizes for the object type (as in the table above) and say so in the spec.

## 3. Write the notes

```
size     W 84" x D 38" x H 34"  (from: sofa seat 18" in image)
ratios   seat h/H .52 · arm w/W .09 · back rake 12° · leg h 4" · cushion count 3
silhouette  track arms flush with back; boxy seat; tight back (no loose back cushions)
colours  body #8a6a4e · legs #2a2522 · piping same as body
gloss    leather semi-matte, visible creases on seat front; legs satin
details  welt on cushion edges; 3 vertical channels on back; brass ferrules on legs
```

The **ratios** line drives Pass 1, and the **gloss** and **details** lines drive Pass 2.

## 4. Matching angle

The shot script's ¾ view is a fixed angle. If the reference is from a different angle, note it (for example "front-left, eye height 4 ft") and compare silhouettes mentally against the nearest view on the sheet. Don't re-render to match the photo angle exactly.
